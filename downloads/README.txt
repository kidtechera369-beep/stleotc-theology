Put your real lesson files here.

The website links to files by the exact path/name listed in
assets/js/data.js (the "downloads" array of each lesson). For example:

  downloads/holy-trinity.pptx
  downloads/holy-trinity.pdf
  downloads/st-cyril.pptx
  ...

To add a new file:
  1) Drop the .pptx / .pdf / .docx into this "downloads" folder.
  2) Add (or edit) the matching entry in assets/js/data.js.

Until you add the real files, the download links will 404 — that's expected.
